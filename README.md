# Davolash 26-39

Davolash ishi 26-39 guruhi uchun Android ilova: dars jadvali, fanlar bo'yicha uyga vazifa va darsliklar,
guruh ro'yxati, lotincha atamalar, testlar, reyting va darsdan oldingi kun eslatmalari.

## APK qanday olinadi
Har safar `main` shoxchasiga o'zgarish yuborilganda GitHub o'zi APK yig'adi
(**Actions → "APK yig'ish"**). Tayyor fayl **Releases** bo'limida `Davolash-26-39.apk` nomi bilan chiqadi.

## Tuzilishi
- `www/index.html` — ilovaning o'zi (Firebase: login va baza)
- `firestore.rules` — bazaning xavfsizlik qoidalari (Firebase konsolida Firestore → Rules ga qo'yiladi)
- `.github/workflows/build-apk.yml` — APK yig'ish
- `icons/` — ilova ikonkasi, `keystore/` — yangilanishlar ustidan o'rnatish uchun doimiy imzo kaliti
